## How Notifications Work

### Automatic Posting System

When maintainers add new internship listings to the repository:

1. **Instant notification** is sent to the Discord server
2. **Details are posted** including company, role, and location
3. **Direct links** to applications are provided
4. **Members are pinged** based on their notification preferences

### Example Notification Format

Notifications typically include:

```text
🚨 NEW INTERNSHIP POSTED 🚨

Company: Tesla
Role: Software Engineer Intern, Applications Engineering
Location: Austin, TX
Date Added: [timestamp]

🔗 Apply: [application link]
```

## Setting Up Notifications

### Discord Notification Settings

<Steps>
  <Step title="Join the Server">
    Click the invite link and accept the Discord server invite
  </Step>
  
  <Step title="Choose Your Channels">
    Navigate to relevant channels:
    - `#internships` - Main internship postings
    - `#new-grad` - New grad positions (if interested)
    - `#discussions` - Community discussions
  </Step>
  
  <Step title="Configure Notifications">
    Right-click the channel name → Notification Settings
    
    Options:
    - **All Messages**: Get notified for every post
    - **@mentions only**: Only for important pings
    - **Nothing**: Mute the channel
  </Step>
  
  <Step title="Enable Mobile Notifications">
    Download Discord mobile app for notifications on-the-go
    
    Configure in app:
    Settings → Notifications → Enable push notifications
  </Step>
</Steps>

<Warning>
  The server can be very active. Consider using "@mentions only" if you find "All Messages" too overwhelming.
</Warning>

## Notification Management

### Avoiding Notification Fatigue

With high activity, consider these strategies:

**Smart Notification Setup:**

```text
High Priority Channels:
- #internships: All Messages (critical updates)
- #announcements: All Messages

Medium Priority:
- #discussions: @mentions only
- Company channels: @mentions only

Low Priority:
- #off-topic: Nothing
- #memes: Nothing
```

**Schedule-Based Approach:**

<Steps>
  <Step title="Active Job Search Period">
    Enable all notifications, check server multiple times daily
  </Step>
  
  <Step title="Between Application Batches">
    Switch to @mentions only, check once daily
  </Step>
  
  <Step title="After Landing Internship">
    Mute most channels but stay connected to help others
  </Step>
</Steps>

### Mobile vs Desktop

**Mobile Notifications:**
- Best for real-time alerts
- Quick checking throughout the day
- Immediate response to time-sensitive posts

**Desktop Experience:**
- Better for extended discussions
- Easier to click application links
- More comfortable for typing longer responses

<Tip>
  Use mobile for staying updated on-the-go, but apply to positions from desktop for a better experience filling out applications.
</Tip>

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="Is the Discord free to join?">
    Yes! The Discord server is completely free. It's maintained by the community and repository creators as a service to students.
  </Accordion>
  
  <Accordion title="Do I need Discord experience?">
    No prior Discord experience is necessary. The platform is user-friendly, and the community is welcoming to newcomers. Simply create a Discord account (free) and join using the invite link.
  </Accordion>
  
  <Accordion title="How many notifications will I receive?">
    During peak recruiting season (August-December), expect several notifications per day in the #internships channel. You can customize your notification settings to manage the volume.
  </Accordion>
  
  <Accordion title="Can I ask for referrals in Discord?">
    Yes, but be professional and respectful. Many servers have dedicated referral channels. Always include relevant information about your background and why you're interested in the company.
  </Accordion>
  
  <Accordion title="What if I miss a notification?">
    Don't worry! All postings remain in the channel history, and the repository serves as the complete source of truth. You can scroll back through Discord or check the GitHub repository directly.
  </Accordion>
</AccordionGroup>
