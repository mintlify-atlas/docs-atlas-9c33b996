## Key features

### 1,700+ verified listings

The repository maintains an extensive database of internship opportunities tracked via GitHub issues and automated workflows. Each listing includes company name, role, location, application link, and posting date.

### Community-driven updates

Listings are contributed and maintained by students and community members. When you submit an internship through a GitHub issue, automated scripts process your contribution and add it to the main README.

### Real-time Discord notifications

Join the [Ouckah Discord server](https://discord.gg/pSaBUXsTkF) to receive instant notifications when new internships are added. This helps you apply right when positions open, giving you a competitive advantage.

### Structured data format

All internship data is stored in a structured JSON format at `.github/scripts/listings.json`, making it easy to search, filter, and integrate with other tools.
